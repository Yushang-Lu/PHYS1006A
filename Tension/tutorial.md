# 液体表面张力系数测量实验

## `tension.tex` 食用说明

本目录包含一份大学物理实验报告 LaTeX 模版，用于整理"液体表面张力系数测量"实验的原始数据、数据处理、现象分析和讨论题答案。

目前文件分工如下：

- `tension.tex`：实验报告正文模版
- `tension.pdf`：已编译出的实验报告 PDF
- `tutorial.md`：本说明文档

建议的使用顺序是：

1. 先在实验中记录原始数据
2. 将测得的数据手动整理到 `tension.tex` 的表格中
3. 根据表格数据完成数据处理部分的不确定度计算
4. 根据实验现象和数据结果补充"实验结论及现象分析"
5. 完成讨论题答案
6. 编译 `tension.tex` 生成实验报告 PDF

## 2. `tension.tex` 的作用与用法

`tension.tex` 是实验报告的主文件。

目前它已经完成了这些工作：

- 设置了报告版式和页眉页脚
- 预留了"实验预习""实验现象及原始数据记录""数据处理""实验结论及现象分析""讨论题"等部分
- 提供了四张原始数据记录表格
- 给出了完整的数据处理过程（含逐差法、不确定度传递）的示例计算
- 给出了实验结论和讨论题的一版示例文字

### 2.1 你通常需要修改哪些部分

建议重点检查和修改：

- 页首的班级、学号、姓名、实验日期
- `\section{实验预习}` 中的两个问题答案
- `\section{实验现象及原始数据记录}` 中四张表格的具体数据
- `\section{数据处理}` 中所有以实测数据为输入的计算过程和结果
- `\section{实验结论及现象分析}` 中关于误差来源和改进措施的分析
- `\section{讨论题}` 中的两个问题答案

特别注意：

- `tension.tex` 当前的数据处理部分是示例数值（如 $D_i = 33.08$ mm、$\Delta V = 0.491$ mV 等），你必须根据自己的实测数据重新计算
- 不确定度计算中涉及的中间量（如 $\sum V_{5-8} - \sum V_{1-4} = 7.856$ mV、$\overline{V} = 1.661$ mV 等）也需替换为你的实际数据
- 游标卡尺的仪器误差（当前为 0.05 mm）和电子秤最小读数（当前为 0.001 mV）请确认是否与你使用的仪器一致
- 相对误差分析与理论值的比较需根据你的实测结果调整

### 2.2 原始数据记录部分怎么填

当前 `tension.tex` 中预留了四张表：

- "吊环的测量"：记录吊环内径 $D_i$ 和外径 $D_o$ 的多次测量值
- "逐差法求 K"：记录不同砝码质量下的增重/减重电压读数
- "室温下表面张力系数测量表"：记录拉脱最大读数 $V_1$ 和吊环读数 $V_2$
- "不同温度下表面张力系数测量表"：记录另一温度下的对应数据

其中常见量的含义大致如下：

- $D_i$、$D_o$：吊环内、外径（mm）
- $V_1'$、$V_1''$：增重、减重读数（mV）
- $V_i$：增重与减重读数的平均值
- $\Delta V$：逐差法求得的每 500 mg 对应的电压变化量
- $K$：仪器的力-电压转换系数（N/mV）
- $V_1$：拉脱瞬间电子秤最大读数
- $V_2$：拉脱后吊环悬空时的读数
- $V_i^\ast = V_1 - V_2$：表面张力对应的净电压
- $\alpha$：液体表面张力系数（N/m）

整理数据时建议注意：

- 单位要与表头保持一致
- 数值位数尽量统一，便于排版
- 逐差法的 8 个 $V_i$ 值需先取增重/减重平均后再做逐差
- 如果某些量需要现场计算，建议先在纸上或计算器中确认后再填入 LaTeX 表格

### 2.3 当前模板里已有的分析内容

`tension.tex` 目前已包含：

- 逐差法求 $\Delta V$、$\overline{K}$ 的完整计算
- 利用误差传递公式分项计算 $(\Delta K/K)^2$、$(\Delta V/V)^2$、$(\Delta L/L)^2$
- 合成相对不确定度 $(\Delta\alpha/\alpha)^2$ 并求出 $\Delta\alpha$
- 两个温度下的表面张力系数结果及与理论值的比较
- 误差来源分析和改进建议
- 两道讨论题的参考答案

这些内容可以直接作为参考，但建议你至少检查以下几点：

- 逐差法公式是否遗漏除以 16 的因子
- $(\Delta V/V)^2$ 项中 $V$ 指的是表面张力电压（1.661 mV 量级），而非逐差法的 $\Delta V$（0.491 mV 量级），不要混淆
- 温度变化对表面张力系数的影响方向是否正确（温度越高 $\alpha$ 越小）
- 讨论题中的表述是否符合老师要求的书写风格

## 5. 常见问题

### 5.1 LaTeX 编译失败

优先检查：

- 是否使用了 `xelatex`
- `tension.tex` 中是否有未配对的括号、公式符号或环境（如 `align*`、`\left` 与 `\right` 配对）
- 表格中是否误写了特殊字符
- `\text{内}` 等中文是否在数学模式中正确处理

### 5.2 不确定度计算数值对不上

优先检查：

- 逐差法是否漏了除以 16（8 个数据点，4 组逐差）
- $(\Delta K/K)^2$ 中的 $V$ 和 $(\Delta V/V)^2$ 中的 $V$ 含义不同，分母不能混用
- 仪器误差是否按均匀分布除以 $\sqrt{3}$
- 游标卡尺的仪器误差取值是否与仪器规格一致（20 分度为 0.05 mm，50 分度为 0.02 mm）

### 5.3 相对误差过大或过小

8% 左右的相对误差在拉脱法测量中是正常范围。如果偏差过大，检查：

- 吊环是否清洁（油污会显著降低表面张力）
- 吊环底面是否与水面平行
- 拉脱过程是否足够缓慢
- 理论值查表温度是否与实测水温一致

### 5.4 LaTeX 编译出现 Warning，但最终生成了 PDF

如果只是 Warning 且 PDF 已正常输出，一般可以先忽略。优先检查表格、公式和中文显示是否正常即可。

### 5.5 表格中出现了多余的 `\frac{d^y}{dx^}` 等乱码

这通常是 AI 辅助工具生成公式时出现的 LaTeX 语法错误。应将其替换为正确的平方符号 `^2`，并检查同一公式中是否有漏掉的括号或上标。
